# awesome-design-md

Source: https://github.com/VoltAgent/awesome-design-md

Each `design-md/<site>/DESIGN.md` is a design-system analysis of that site (palette, typography, layout, components, motion). `README.md` lists all sites.

## Usage
1. List available references: `ls design-md/` (relative to this skill directory).
2. Read `design-md/<site>/DESIGN.md` for the requested or closest-matching site.
3. Apply its tokens and rules to the UI being built. Adapt, don't copy brand assets or logos.
